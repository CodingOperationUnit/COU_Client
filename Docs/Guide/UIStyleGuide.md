# UI 스타일 가이드

탕탕특공대 레이아웃에 GUIPack-Clean&Minimalist 에셋을 입힐 때 따르는 시각 규칙이다.
팩 에셋의 경로, 구조, 적용 방법은 `Docs/Guide/GUIPack_CleanMinimalist.md`를 본다. 아래 색 값은 모두 그 문서 3.3의 팩 팔레트에서 골랐다.

## 0. 배경
- 기존 UI는 2D Sprite 패키지의 기본 도형(Square, Circle, Triangle, Hexagon)에 단색을 입힌 그레이박스다. 남색 면(`#1F1F29`, `#2E3040`, `#3E4250`)에 노랑 강조(`#FFC61A`, `#FFD60C`)를 써서 레퍼런스의 배치와 색만 흉내 냈다.
- 새 팩은 탕탕특공대와 성격이 정반대다.

| 항목 | 탕탕특공대 레퍼런스 | 새 팩 |
|---|---|---|
| 형태 | 두꺼운 검정 외곽선, 사선, 리본 배너 | 외곽선 없음, 둥근 모서리, 얇은 stroke |
| 색 | 고채도 노랑·주황, 원색 | 회청색 면과 절제된 강조색 |
| 아이콘 | 컬러 일러스트 | 흰색 단색 |
| 글자 | 굵은 디스플레이체 | Roboto 가는 굵기 |

## 1. 방향
- **하이브리드**: 형태, 면 색, 아이콘은 팩을 따른다. 고채도 강조색은 게임에서 의미가 큰 곳(메인 버튼, 승리·패배 배너, 보스 경고, HP)에만 쓴다.
- 레퍼런스(`Assets/UIReferences`)에서는 배치와 기능만 가져온다. 외곽선, 사선, 리본 배너, 컬러 일러스트 같은 외형은 가져오지 않는다.
- **테마는 Dark 하나만** 쓴다. 전투 필드 위에 HUD를 얹고 팝업을 Dim 위에 띄우는 구조에 맞고, 기존 UI도 어두운 계열이다.

## 2. 모양
| 용도 | 모양 | 스프라이트 (`Shapes/` 아래) | ppuMul |
|---|---|---|---|
| 패널, 버튼, 카드, 슬롯 | Sharp Rounded | `Semi Rounded/Semi Rounded`, 외곽선은 `Semi Rounded - Stroke 4px` | 2 |
| 아이콘 버튼 (퍼즈, 음소거) | Circle | `Circle/Circle - 256` | - (Simple) |
| 배지 (재화, New!, 개수) | Rounded (알약형) | `Rounded/Rounded` | 3 |

## 3. 색
- 모든 색은 단색이다. 그라디언트는 쓰지 않는다. 팩의 `Gradient` 프리팹 변형과 `Ricimi.Gradient` 컴포넌트도 쓰지 않는다.

### 3.1 면과 텍스트
| 역할 | 값 |
|---|---|
| 패널 | `#2C3642` |
| 헤더 (팝업 상단 바) | `#1C232A` |
| 구분선 | `#374355` |
| Dim | `#00000099` (기존 팝업 값 유지) |
| 텍스트 기본 | `#FFFFFF` |
| 텍스트 보조 | `#C9D3DF` |

### 3.2 버튼
| 역할 | 예 | 값 |
|---|---|---|
| 메인 | 게임 시작 | Yellow `#FFB700`, 글자 `#28313C` |
| 확인 | 계속하기 | Green `#00C45D` |
| 위험 | 종료 | Red `#FA5252` |
| 일반 | 그 밖의 버튼 | Dark `#455D73` |

### 3.3 게임 의미색
| 역할 | 값 |
|---|---|
| 플레이어 HP, 보스 HP, 보스 경고 | Red `#FA5252` |

| 패배 배너 | Blue `#078CE4` |

### 3.4 등급

| 등급 | 현재 | 변경 |
|---|---|---|

| 고급 | `#8FE605` | Green `#00C45D` |
| 희귀 | `#0A90FF` | Blue `#078CE4` |

## 4. 아이콘
- 팩 아이콘은 흰색 단색이다. 색은 `Image.color`로 입힌다.
- 기본은 흰색, 보조 요소는 `#C9D3DF`, 의미가 있는 곳은 3장의 색을 쓴다.

## 5. 글자

### 5.1 폰트
- 한글 텍스트는 `NanumGothicBold SDF` 하나만 쓴다. 굵기가 하나뿐이라서 위계는 크기(5.2)와 색(3.1의 기본, 보조)으로만 나눈다.
- 숫자 전용 텍스트(타이머, 골드, 킬 수, 데미지 숫자)는 팩의 Roboto를 쓴다. Display 단계와 버튼 안 숫자는 `Roboto-Bold SDF`, 나머지는 `Roboto-Medium SDF`다. Roboto에는 한글이 없으므로 한글이 섞이는 텍스트에는 쓰지 않는다.

### 5.2 크기 단계
글자 크기는 아래 7단계만 쓴다. 최소는 24다.

| 단계 | 크기 | 쓰는 곳 | 기존 값 |
|---|---|---|---|
| Display | 112 | 전투 타이머, 결과창 경과시간 | 106, 124 |
| H1 | 72 | 스테이지 이름, 결과·보상 배너, 보스 경고 | 56~88 |
| H2 | 52 | 팝업·창 제목, 리본 배너, L 버튼 | 44~54 |
| Body L | 44 | 카드 이름, 안내 문구, M 버튼 | 40~48 |
| Body | 36 | 본문 메시지, 수치, S 버튼 | 32~40 |
| Caption | 28 | 라벨, 설명, 수량, 배지 | 24~32 |
| Small | 24 | 메뉴 아이콘 라벨, 남은 시간 | 16~22 |

## 6. 크기
- 캔버스 기준은 1080x1920(Match Width)이다. 모든 크기는 4의 배수, 높이는 8의 배수로 잡는다.
- M 버튼이 팩 기본 버튼(높이 90, 글자 34)의 1.33배다.

### 6.1 버튼
| 단계 | 높이 | 최소 폭 | 글자 | 쓰는 곳 | 기존 값 (높이 / 글자) |
|---|---|---|---|---|---|
| L | 144 | 360 | 52 | 게임 시작, 결과 확인, 계속하기(퍼즈창, 행운열차) | 138~172 / 52~64 |
| M | 120 | 280 | 44 | 팝업 확인·취소, 종료, 선택, 도전 시작 | 122~142 / 46~52 |
| S | 96 | 180 | 36 | 패널 안 보조 버튼(장착, 레벨업, 일괄 레벨업) | 60~80 / 26~32 |

### 6.2 아이콘 버튼과 배지
| 종류 | 크기 | 아이콘 | 쓰는 곳 |
|---|---|---|---|
| 아이콘 버튼 L | 원 128 | 64 | 퍼즈, 홈, 사운드, 뒤로가기 |
| 아이콘 버튼 M | 원 96 | 48 | 팝업 닫기, 정렬 |
| 배지 (알약형) | 높이 56 | - | 재화, 등급, New!, 개수. 글자는 Caption(28) |
| 알림 (!) | 원 40 | - | 탭과 메뉴의 새 소식 표시 |

### 6.3 터치 영역
- 터치 영역은 최소 96x96이다. 플랫폼 권장값(44pt, 48dp)을 1080 폭으로 환산한 약 120보다 작지만, S 버튼 단계를 두기 위해 96으로 정했다.
- 이보다 작게 보이는 버튼(재화 옆 + 버튼 등)은 투명 영역을 덧대 터치 영역을 96까지 넓힌다.
